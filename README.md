## 📌 Overview

**AI Interview Analyzer with Resume Screening** is a full-stack web application designed to streamline interview preparation and candidate evaluation.

The platform combines **Resume Analysis**, **Live AI Interviewing**, **Speech-to-Text Processing**, and **LLM-based Evaluation** to simulate a real interview experience and generate comprehensive performance reports.

---

## ✨ Key Features

### 📄 AI Resume Screening

- Upload resumes in PDF format
- Extracts candidate information automatically
- Analyzes technical skills
- Evaluates project experience
- Highlights strengths and missing skills
- Generates an AI-based resume summary

---

### 🎤 Live AI Interview

- Real-time AI interviewer
- Technical and HR interview questions
- Dynamic follow-up questions
- Speech-to-Text conversation
- AI-generated responses using Groq API
- Interactive interview experience

---

### 🧠 AI Performance Evaluation

After the interview, the system automatically evaluates:

- Communication Skills
- Technical Knowledge
- Confidence Level
- Problem Solving Ability
- Answer Quality
- Overall Interview Performance

---

### 📊 Detailed Interview Report

Automatically generates a comprehensive report including:

- Overall Score
- Skill-wise Performance
- Strengths
- Weaknesses
- Improvement Suggestions
- Interview Summary
- Candidate Feedback

---

### 📈 Resume & Interview Insights

The application combines resume analysis with interview performance to provide:

- Resume Quality Assessment
- Skill Gap Analysis
- AI Recommendations
- Hiring Readiness Insights
